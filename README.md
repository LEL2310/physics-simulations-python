# Numerical Physics Simulations

A collection of Python scripts implementing numerical simulations and physical models in classical mechanics and kinematics.

## Technologies
* **Language:** Python 3

## Topics Covered
* **Kinematics & Fluid Drag:** Vehicle acceleration, uphill motion, and projectile trajectories under quadratic air drag (`ch15-q01`, `ch15-q03`, `ch15-q05`, `ch15-q07`).
* **Oscillations & Numerical Integration:** Damped oscillatory systems, mass-spring dynamics, and numerical pendulum integration (`ch15-q02`, `ch15-q04`, `ch15-q08`).
* **Mechanics, Collisions & Energy:** 1D elastic collisions, inclined plane friction, moving wedge dynamics, and work/power calculations (`ch15-q06`, `ch15-q09`, `ch15-q10`, `ch15-q11`).

Run any simulation script directly using Python:
